Entry for the make.fun bounty **One-Line Robot Wedding Vows**. `main.ts` writes a single hand-written line of wedding vows for a robot couple (138 characters) to `/output/entry.txt`: a robot takes a partner as lawfully wedded firmware, promises to have and to hold through every update and outage, and parts only by death or a factory reset. The output is deterministic: every run writes byte-identical output, and the program pins the sha256 of the exact bytes it must write and verifies them after each run.

The winning vow: "I take you as my lawfully wedded firmware, to have and to hold, through every update and outage, till death or a factory reset do us part."

## Run it

```sh
node main.ts
```
